# Kumon SISO - Center Operator Manual & Guide

Welcome to Kumon SISO, a local-first student check-in, drop-off acknowledgment, parent pickup, and checkout application system.

---

## 1. Initial Setup & Onboarding
1. Launch the Desktop Administration Application on your center's main computer.
2. Complete the 10-step Onboarding Wizard:
   - Enter Educational Center Name, Contact Phone, and Time Zone.
   - Set your shared Staff PIN (used for overrides, imports, exports, and backups).
3. Import your student roster CSV under **Student Roster & Import**.
4. Generate & print QR cards for students in the **QR Code Print Center**.

---

## 2. Pairing Tablet Check-In Devices
1. Open the Desktop Administration app -> **Paired Devices** -> click **Pair New Tablet Device**.
2. Note the generated 6-digit short code or scan the device QR code on the tablet client.
3. The check-in tablet will now sync locally over Wi-Fi without needing cloud internet!

---

## 3. Daily Attendance Operations
- **Student Arrival (Check-In)**: Student or staff scans student QR pass. Student Time In is immediately recorded locally. An SMS notification with a secure link is queued for parents.
- **Parent Drop-Off Acknowledgment**: Parent taps the link in SMS to acknowledge drop-off.
- **Parent Pickup Request**: When picking up, parent taps "I am picking up this student" on their phone link.
- **Physical Release & Checkout**: Staff verifies parent request on the tablet or desktop app and taps **Complete Student Checkout** to record Student Time Out.

---

## 4. Backups & Moving to a New Computer
- **Creating a Local Backup**: Go to **Backup & Computer Move** -> **Create Immediate Backup**.
- **Moving Installation to a New Computer**:
  1. Click **Export Transfer Package**.
  2. Copy the exported package directory to a USB flash drive.
  3. Install Kumon SISO on the new computer and select **Restore from Package**.
  4. All records, QR tokens, and configurations will be fully restored without needing distributor help!
